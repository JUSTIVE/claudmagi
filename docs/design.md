# claudmagi — 디자인 노트

참고 영상: `~/Downloads/HRxKPCOaoAAn4b7.mp4` (854×480, 15fps, 15.4s). 프레임 추출 관찰 결과.

## 전체 인상
- 배경은 선명한 주황(약 `#F04A0E`), 미세한 도트 텍스처.
- PCB 트레이스 / 지하철 노선도 느낌의 얇은 검은 선들이 수평 → 45° 대각선 → 수평으로 흐른다.
  대각선 구간은 서로 평행하게 묶여 "밴드"를 이룬다.
- 선 위에 검은 둥근 사각형 "칩"이 얹혀 있고 라벨은 민트 그린(약 `#3BE38A`) 대문자 고정폭 글꼴.
  대각선 위의 칩은 45° 회전, 수평 구간의 칩은 수평.
- 선을 따라 작은 검은 점(패킷)이 이동한다.

## 상태 표현
| 상태 | 표현 |
|------|------|
| 작업 중 (연결) | 검은 칩 + 녹색 라벨, 선이 칩을 관통 |
| 입력 필요 / 완료 (분리) | 선이 느슨한 케이블 모양(S자 파형)으로 늘어진 뒤 홈(notch)이 파인 검은 소켓 블록에서 끝남. 칩은 소켓에서 떨어져 나가 있고, 색은 어두운 적갈색 + 앰버 라벨 |
| 호버 | 칩 주위 흰색 1.5px 외곽선, 포인터 커서 |
| 등장 | 아래→위 순으로 칩이 주황빛 반투명에서 검정으로 페이드인 |
| 스크롤 | 세로 스크롤로 더 많은 레인을 볼 수 있음 |

## claudmagi 매핑
- 세션 1개 = 칩 1개. 라벨은 `~/.claude/sessions/<pid>.json`의 `name` 대문자.
- `status == busy` 이고 `waitingFor` 없음 → 연결 상태.
- `waitingFor` 있음(권한/다이얼로그) 또는 `tempo/state == blocked` → 분리 + 앰버(입력 필요).
- `status == idle` → 분리 + 어두운 앰버(완료).
- 클릭 → 해당 세션의 Warp 탭으로 이동 (`WARP_FOCUS_URL=warp://session/<uuid>` 를 프로세스 환경에서 읽어 `open`).

## 치수(디자인 단위)
- 기준 크기 980×620. 창이 더 크면 `zoom = clamp(sqrt(면적비), 1, 2.6)` 배로 전체를 확대해 밀도를 유지한다(4K 전체화면 대응, #9).
- 레인 간격 16, 선 굵기 1.6, 대각선 낙차 128(=8×16), 모서리 반경 8
- 레인은 하나의 계단: 레인 i는 폭의 62% 지점에서 시작해 i마다 16씩 왼쪽에서 꺾인다 → 꺾임이 45° 스트라이프를 이룬다.
  넓은 창에서는 폭의 55% 간격으로 스트라이프를 반복(`bands`)해 오른쪽 아래까지 채운다. 이 구성은 선이 절대 교차하지 않는다.
- 레인 수는 높이를 채울 만큼 늘리고, 위쪽에 보조 레인 8개(`LEAD_LANES`)를 두어 오른쪽 상단도 채운다.
- 세션 k → 레인 `LEAD_LANES + 1 + k`, 짝수 k는 대각선 위(45° 회전), 홀수 k는 대각선 끝 +70px 수평 구간
- 칩 높이 22, 모서리 4, 좌우 패딩 13, 최소 폭 56
- 라벨: 자체 스트로크 벡터 폰트(4×6 유닛 격자, 1.5px/유닛) — 45° 회전을 위해 경로로 렌더링
- 소켓 24×14, 홈 6×6, 분리 시 칩 이동 16, 파형 길이 46, 진폭 6

## 검증 방법
화면 캡처 권한이 없어도 `cargo run -- --svg out.svg --demo --size 1920x1080` 로 같은 장면을 SVG로 뽑고 `swift tools/svg2png.swift out.svg out.png` 로 정확한 크기의 PNG를 만들어 확인한다. (Quick Look 썸네일은 비율을 무시하므로 쓰지 않는다.)
